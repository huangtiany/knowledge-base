Transformer 架构极简拆解

所属栏目：AI/Agent 标签：LLM基础 深度学习 最后更新：2026-09-05

这篇文章记录了我重新推导 Transformer 架构的过程。在之前的学习中，我总是对注意力机制的缩放因子感到困惑，今天终于理顺了。

1. 为什么需要 Self-Attention？

在 RNN 时代，序列信息的传递是串行的，这导致了两个致命缺陷：无法并行计算，以及长距离依赖的梯度消失问题。Self-Attention 的本质是让序列中的每一个 Token 直接与所有其他 Token 计算相关性。

2. Q, K, V 的本质理解

打个比方，你去图书馆找书：

  • Query (Q)：你的搜索意图（比如：“找一本关于机器学习的书”）
  • Key (K)：每本书书脊上的标签（“计算机科学”、“人工智能”）
  • Value (V)：这本书的具体内容

3. 核心代码实现

下面是缩放点积注意力（Scaled Dot-Product Attention）的精简 PyTorch 实现：

import torch
import torch.nn.functional as F
import math

def attention(query, key, value, mask=None):
    # query shape: (batch_size, num_heads, seq_len, d_k)
    d_k = query.size(-1)
    
    # 1. 计算注意力分数 Q * K^T / sqrt(d_k)
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)
    
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
        
    # 2. Softmax 归一化
    p_attn = F.softmax(scores, dim=-1)
    
    # 3. 乘以 Value
    return torch.matmul(p_attn, value), p_attn
